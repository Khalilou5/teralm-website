## What is Teralm?

**Teralm** condenses three meanings:

- **Tera** — from *Teranga*, the West African value of hospitality and warmth
- **Alm** — from *alma*, soul in Latin
- **LM** — Language Model, the technical core of modern AI

Teralm is the African Language Model. Made with soul, to serve humanity.
